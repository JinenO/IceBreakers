# IceBreakers

##  Main Features

IRIS FLOW uses a **Vision-based Single Switch Scanning** interface. Patients do not need to perform precise eye movements; they simply wait for the auto-scanner to highlight their desired option and perform a **deliberate blink (1.2s)** to confirm.

### 1.  Quick Needs (Basic Care)
Designed for rapid communication of essential physiological and comfort requirements to ensure immediate response from caregivers.
* **Water** (Thirsty)
* **Food** (Hungry)
* **Toilet** (Restroom assistance)
* **Suction** (Clear airway)
* **Position** (Adjust bed/body posture)

### 2.  Smart Predictive Keyboard
A fully functional on-screen keyboard optimized for low-effort input.
* **Smart Prediction:** Suggests words dynamically to drastically reduce typing time.
* **Dual Mode:** Send messages directly to a caregiver's phone, or switch to Search Mode to find YouTube videos.
* **Text-to-Speech (TTS):** Speaks the typed message aloud instantly.

### 3.  Accessible Media Player
An entertainment hub that can be navigated entirely hands-free.
* **YouTube Integration:** Search, select, and play YouTube videos without a mouse.
* **Local Media:** Watch pre-loaded family videos or listen to music/audiobooks.
* **Gaze-Friendly Controls:** A custom control panel with large, scannable buttons (Play, Pause, Rewind, Volume).

### 4.  Body & Discomfort Reporting
Allows patients to pinpoint exactly where they are experiencing pain or discomfort (e.g., Head, Leg, Itch, Temperature) without needing to spell it out.

### 5.  Chat AI (Companion)
An AI-powered conversational interface designed to assist users in drafting complex thoughts or providing daily companionship.

##  Core System Capabilities

| Feature | Description |
| :--- | :--- |
| **Auto-Scanning Engine** | Hands-free navigation with customizable scanning speed (default: 2.5s per item). |
| **Anti-Midas Touch** | Requires a sustained blink (1.2s) to confirm, completely eliminating accidental clicks from natural blinking. |
| **Sleep Mode** | Automatically pauses the scanning system when the user's eyes are closed for an extended period to prevent fatigue. |
| **SOS Alarm** | Continuous eye closure triggers a high-priority alarm to alert caregivers of a potential emergency. |
| **Developer Mode** | A built-in bypass (`?dev=1`) that allows developers to use mouse clicks for rapid testing without requiring camera input. |
